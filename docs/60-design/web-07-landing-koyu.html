03 — GEREKÇE

Her teknoloji neden burada

Soldan bir teknoloji seç; nasıl entegre edildiğini, hangi kararların alındığını ve hangi tuzağa düşüldüğünü gör.

nginx KENAR

Uygulamanın tek giriş kapısı. Aynı anda hem statik sunucu hem reverse proxy.

Tek origin, sıfır CORS

Frontend, API ve Kratos tek adres üzerinden servis edilince tarayıcı için hepsi aynı origin olur.

Servisler dışarı açılmıyor

Dışarıya yalnızca 80 portu açık. Portföy servisi, Kratos ve Redis host üzerinde hiç yayınlanmıyor.

Son imajda Node yok

Multi-stage build ile React derlenir, son imaja yalnızca statik çıktı ve hafif nginx girer.

web/nginx.conf PROD CONF 
server {
    listen 80;
    root /usr/share/nginx/html;   # React build ciktisi
    index index.html;

    location /api/ {
        proxy_pass http://portfolio-service:5001;  # ONEK KORUNUR
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header Cookie $http_cookie;
    }

    location /ory/ {
        proxy_pass http://kratos:4433/;            # ONEK ATILIR (sonda slash var)
    }

    location / {
        try_files $uri $uri/ /index.html;          # SPA fallback
    }
}

proxy_pass sonundaki eğik çizgi her şeyi değiştiriyor

LOCATION PROXY_PASS GELEN İSTEK ARKAYA GİDEN
/api/ portfolio-service:5001 /api/assets /api/assets
/ory/ kratos:4433/ /ory/sessions/whoami /sessions/whoami
warning
Tuzak: location ile proxy_pass uyumsuzluğu.
Kural basit: location ve proxy_pass ya ikisi de eğik çizgiyle bitsin ya da hiçbiri. Birini unuttuğunuzda yönlendirme kök adreste sessizce 404 üretir.
