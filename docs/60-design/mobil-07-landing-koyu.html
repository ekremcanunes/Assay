// nginx.conf rate limit kuralı
limit_req_zone $binary_remote_addr zone=api:10m rate=15r/s;
location /api/v1/telemetry {
limit_req zone=api burst=5 nodelay;
proxy_pass http://dotnet_upstream;
}

Bilinçli Ödünler

Mühendislik, neleri yapmayacağını bilmektir. Bu projede tavizsiz tercih edilen mimari kararlar:

Postgres > NoSQL Tercihi

Portföy ve bakiye hareketleri finansal ACID tutarlılık gerektirir. Şema esnekliği yerine sıfır veri kaybı önceliklendirildi.

Client-Side BIST 30 Arama

Tüm hisse sembolleri ilk yüklemede 22KB JSON olarak tarayıcı belleğine aktarılır; klavye vuruşları sunucuya network maliyeti bindirmez.

Veri Uydurmama İlkesi

Harici API çökerse sahte/tahmini rakam üretilmez. Sistem doğrudan açıkça "STALE_CACHE_FALLBACK" uyarısı verir.
