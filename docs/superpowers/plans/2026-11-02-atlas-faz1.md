# Atlas Faz 1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `atlas/` altında, "02 Teslimat" akışını onaylanan mockup kalitesinde (masaüstü + mobil) gösteren, Vercel preview'a çıkan bir React uygulaması kurmak.

**Architecture:** Vite + React statik site. İçerik `atlas/content/` altında YAML; build öncesi bir Node betiği içeriği doğrular (şema, terim atıfları, dosya yolları, gizli bilgi kalıpları). Akış sahnesi kendi SVG çizicimizdir; masaüstünde şeritli yatay sahne, `md` altında dikey zincir.

**Tech Stack:** React 19, react-router-dom 7, Vite 8, `@vitejs/plugin-react` 6, `js-yaml` 4, düz CSS (CSS değişkenleri), Google Fonts yok — `@fontsource-variable/plus-jakarta-sans` + `@fontsource/jetbrains-mono`.

**Spec:** `docs/superpowers/specs/2026-11-02-atlas-design.md`

## Global Constraints

- Assay'ın `web/` sürümleriyle aynı: `react` / `react-dom` `^19.2.6`, `react-router-dom` `^7.18.3`, `vite` `^8.0.12`, `@vitejs/plugin-react` `^6.0.1`.
- Atlas Assay'ın hiçbir dosyasını import etmez; yalnız `content/` içindeki `file` alanları repo dosyalarını **yol olarak** gösterir.
- Yalnız koyu tema, yalnız Türkçe.
- Renk değerleri (mockup'tan): `--bg #070B14`, `--card #0F172A`, `--line #1E293B`, `--line2 #273449`, `--ink #E2E8F0`, `--mute #8B9BB4`, `--dim #56657E`, `--cob #3B82F6`, `--cob2 #60A5FA`, `--em #10B981`, `--amb #FBBF24`; şerit tonları GitHub `#A78BFA`, AWS `#FB923C`, EC2 `#34D399`.
- İçerikte yasak: AWS hesap ID'si (12 haneli sayı), `arn:aws`, IPv4 adresi, bucket adı, secret adı/değeri. Gerekirse `<deploy rolü>` gibi yer tutucu.
- İçerik metni `docs/10-standards/WRITING.md` `YZ-01`–`YZ-08`'e uyar (kısa cümle, bir terim bir anlam).
- Mobil: `max-width: 767px` altında dikey zincir; yatay taşma yok (`scrollWidth === innerWidth`); dokunma alanı ≥ 44px.
- `prefers-reduced-motion: reduce` → paket animasyonu, akan çizgi ve otomatik oynatma kapalı.
- Kullanıcı testi kendisi yapar: her görev **derleme kontrolü** (`npm run build`) + **elle kontrol listesi** ile biter; otomatik test yazılmaz.
- Commit mesajında Claude imzası / co-author satırı yok.
