3 / 6 · Üç image build edilir, ECR'a gönderilir

Ne oluyor
market-service, portfolio-service ve web image'ları build edilir. Tag = commit SHA.
Neden böyle
SHA tag'i her sürümü tekil yapar. EC2'de tam olarak CI'da build edilen image çalışır (immutable).
Bedeli / alternatif
latest tag'i daha basit ama hangi sürümün çalıştığı bilinmez, geri dönüş zorlaşır.
Dosya · komut
.github/workflows/build-push.yml docker build -t $REG/assay/web:$SHA ./web docker push $REG/assay/web:$SHA
